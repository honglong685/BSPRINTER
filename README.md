# BSPRINTER 软件说明

> 标签 / 条码设计与批量打印工具 · Win32 原生桌面程序
> 技术栈：Win32 API + C++20 + GDI/GDI+ + ODBC/MySQL，Unicode，无第三方 UI 框架（QR 用 Nayuki qrcodegen，MIT）
> 当前版本基于 `E:\BSPRINTER\BSPRINTER`（工程名 `BSPRINTER`）

---

## 1. 软件概述

BSPRINTER 是一款面向**标签 / 条码**场景的桌面设计与打印工具。用户在可视化设计器中摆放文本、条码、线条、矩形、图片等对象，绑定数据库（MySQL / ODBC）或文件（Excel / TXT）数据源，通过 `{字段名}` 占位符把每一行数据批量套印到标签上。支持多联排版（一页多枚）、整页旋转、逐对象旋转、扫描枪即时录入、模板锁定、中英文界面切换与机器码授权。

适用于：商品价签、快递面单、库存条码、自提码、配货标签等需要"一张模板 + 一批数据 = 一堆标签"的场景。

## 2. 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（x64 或 x86） |
| 图形 | GDI/GDI+（系统自带），建议屏幕 DPI ≥ 96 |
| 数据库直连 | 需 `libmysql.dll`，且**位数必须与 exe 一致**（x64 配 x64、x86 配 x86） |
| ODBC | 系统自带 `odbc32`；Excel 数据源依赖 Microsoft Excel ODBC 驱动 |
| 打印机 | 任意 Windows 打印机；亦支持"Microsoft Print to PDF"导出 PDF |
| 数据 | `.lbl` 模板文件（程序默认关联） |

## 5. 快速上手

1. **新建模板**：`文件 → 新建`（或 `Ctrl+N`）。
2. **设置标签**：`设置 → 标签设置`，填标签宽/高（毫米）、每页排几列几行、整页旋转、打印机、页边距。
3. **画对象**：在工具栏选 文本/条码/图片/直线/矩形，在画布拖拽画出；右侧属性面板细调。
4. **绑定数据**：在文本或条码里写 `{字段名}`（或 `[字段名]` / `$字段名$`）；在"标签设置"里选数据源（数据库 SQL 或 Excel/TXT 文件）。
5. **打印**：`文件 → 打印`，选打印机与份数；若 SQL 带参数会弹出参数框，逐条录入后回车即打印；带扫描枪的条码会在打印前弹窗等待扫入。

## 6. 数据源

### 6.1 四种来源

| 类型 | 配置位置 | 说明 |
|---|---|---|
| MySQL 直连 | 数据库设置 → MySQL | 动态加载 `libmysql.dll`（位数须匹配），数据库 `pslable` 等 |
| ODBC | 数据库设置 → ODBC | 系统 DSN（如 `data`）或连接串 |
| Excel | 标签设置 → 文件 | 选 `.xlsx` 与工作表（如 `Sheet1$`） |
| TXT | 标签设置 → 文件 | 英文逗号分隔、首行为列名 |

取数统一走 `ResolveDbConfig`：优先用模板内绑定的连接（`DbConnSetting`），未绑定则回退程序 `BSPRINTER.ini [Database]`。

### 6.2 存储过程（JOINFUPEI）

调用形如 `CALL JOINFUPEI(?, ?, ?)`，三个入参（货号 / 条码 / 促销）。**任一入参为 NULL 会返回"表头占位行"**，因此空参数会被替换为 `''` 而非 `NULL`。返回的 8 个定长列直接作为字段供占位符使用。

### 6.3 扫描枪输入

条码对象可勾选"来自扫描枪"。打印前程序弹出录入框（行数=待扫条码数），扫码枪扫入或手工输入、回车即继续；未扫满会跳到第一个空行；取消则中止本次打印。扫入值**不写入模板**，打印后自动清空。

## 7. 占位符与字段替换（打印时生效）

- 只识别显式占位符：**`{列名}` / `[列名]` / `$列名$`**（裸列名不再作为占位符）。
- 命中占位符时，对"该字段的值"应用数字格式（值级小数位控制）：
  - 文本对象开启"数字格式"后，由 `numDecimals` 控制小数位（只格式化来自数据库的值，手写文字/数字不动）。
  - 例：`零售价 1件：{零售价}` → `零售价 1件：58.77`。
- 字符分割：可在属性面板设置"分割长度 + 分隔符"，占位符替换后按规则切分（如 `6,2` + `-`）。
- 图片对象：按绑定字段值解析图片路径，实现"一行数据换一张图"。
- 未匹配占位符会记录并在打印后提示，全程写入 `BSPRINTER_debug.log`。

## 8. 打印

- **多联排版**：一张物理页排 `列数 × 行数` 个标签单元格，自动居中。
- **整页旋转**：0 / 90 / 180 / 270 度，在"标签设置"选择，整页内容旋转后落到单元格。
- **页边距**：左/右/上/下（毫米），打印时在"纸张−边距"可用区内居中；支持双向联动（输入一边自动推算对边）。
- **防白纸三道闸**：① 首行全空 / 表头占位行取消；② `HasPrintableContent` 判可画内容；③ `SetupPaper` 句柄替换（`ResetDCW`）确保纸张生效。
- **参数流程**：带 `?` 参数的 SQL → 常驻参数对话框，可连续打印；勾选"打印后保留"的参数打印后不清空，并自动回存 `.lbl`。
- **开发者自测**：`BSPRINTER.exe --test-numfmt`（数字格式 12 例，写日志）、`--test-callparam`（弹参数框）、`--test-scaninput`、`--test-lang`。

## 9. 模板文件 `.lbl`

UTF-8 with BOM 的 INI 风格文件：

```
BRPRINTER_LABEL_TEMPLATE 1
[Label]
Width=...
Height=...
PaperWidth=...
PaperHeight=...
PaperCols=...
PaperRows=...
Rotation=0
Printer=...
QuerySql=...
DataSourceFile=...
DataSheet=...
MarginL/R/T/B=...
Locked=1
DbBound=...  DbType=...  DbHost=...  DbPort=...  DbUser=...  DbPass=ENC:...  DbName=ENC:...
ParamKeep=...
[Object.1]
Type=Text
...
```

- 敏感项（Host/User/Pass/DbName）用 `dbcrypto`（AES-128-CBC）加密，存为 `ENC:<base64(IV‖密文)>`。
- 打开 `.lbl` 后强制进入**锁定**状态：只允许选中 / 平移 / 缩放，禁止编辑（标题栏显示 `[已锁定]`）。
- 老模板缺键自动取默认值，兼容加载。

## 10. 授权 / 注册

- **机器码**：卷序列号 + CPU 标识符 + 固定盐 → SHA-256 → 前 8 字节 → 16 位十六进制（显示每 4 位插 `-`）。
- **注册码**：RSA-2048 PKCS#1 v1.5 签名（确定性），一机一码；`设置 → 注册` 粘贴后离线验签（`license_pubkey.h` 内嵌公钥），存 `BSPRINTER.ini [License] RegCode`。
- 未注册时每日提示一次试用。
- ⚠️ 重生成密钥对会覆盖 `privkey.dat` 与 `license_pubkey.h`，**此前所有注册码失效**；`privkey.dat` 切勿入库。

## 11. 中英文切换

`设置 → English / 中文` 即时切换界面（菜单与对话框 STATIC/BUTTON 文本）。以"中文原文为键"做运行时翻译，未翻译项自动退化中文；字体名 / ini 键 / SQL / 路径等绝不翻译，以保证兼容性。语言持久化于 `BSPRINTER.ini [Settings] Language=zh|en`。

## 12. 构建与开发

  - 注意：工程用 MSVC `cl.exe` 直接编译，**不能走 bash 里的 `cl`**（沙箱会拦截），务必用脚本。
  - **新增 / 删除源文件须同时改两处**：`build_bsprinter.py` 的 `sources` 与 `BSPRINTER.vcxproj`（4 个配置），否则报 `LNK2019`。

## 13. 已知约定与注意

- **坐标一致性**：绘制与命中必须共用同一偏移，否则对象"漂浮"。
- **线型坑**：非实线线宽 > 1 时，内置装饰画笔会被忽略画成实线；本程序用 `ExtCreatePen` 几何画笔解决（世界变换仅旋转无缩放，不会二次缩放线宽）。
- **设计态条码兜底**：内容为空 / 含占位符 / 编码失败时渲染 `ABC123456`（EAN-13 降级为 `123456789012`），绝不显示"无效条码"红字——这是设计行为，非 bug。
- **模板锁定**：打开 `.lbl` 后强制锁定，需先解锁才能编辑。
- **MySQL 位数**：`libmysql.dll` 必须与 exe 同位数。
- 详细代码地图见 `E:\BSPRINTER\CODE_MAP.md`。
